# CinemaManagement

## Problem

Managing a cinema manually can make it difficult to manage movies, rooms, showtimes, seats, and bookings. When multiple customers select seats for the same showtime, it can also lead to seat conflicts or incorrect seat status.

## Solution

CinemaManagement is developed to digitalize cinema management and ticket booking processes, including movie, room, showtime, seat, and ticket management.

The system uses **SignalR** to update seat status in real time between users, helping prevent multiple users from booking the same seat.

## Project Description

**CinemaManagement** is a cinema management and movie ticket booking system built with **ASP.NET Core MVC**.

### Main Features

* Manage movies and genres.
* Manage cinemas, rooms, and seats.
* Manage showtimes.
* Book tickets and process payments.
* Manage users and roles.
* Real-time seat status updates using **SignalR**.
* Revenue statistics and reports.

## Technologies

* C# / ASP.NET Core MVC
* Entity Framework Core
* PostgreSQL
* SignalR
* FluentValidation
* HTML / CSS / JavaScript
